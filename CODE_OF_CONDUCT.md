# Community code of conduct

Everyone is welcome to use, learn from and contribute to Nanodeploy, regardless
of background or experience. Be respectful, assume good intent and focus
criticism on the work. Help newcomers understand the context.

Harassment, threats, discriminatory language, unwanted sexual attention and
publishing another person's private information are unacceptable. Do not share
credentials or private deployment details in issues, pull requests or discussions.

Maintainers may edit or remove inappropriate content, close disruptive
conversations, or restrict participation. They should apply these expectations
consistently and explain moderation decisions when doing so is appropriate.

Report abusive content using GitHub's reporting tools or contact a repository
maintainer privately. Share only the information needed to assess the report.
Security vulnerabilities follow [SECURITY.md](SECURITY.md).
